# تحديث جدول الجرعات

1. افتح `data/dose-rates.csv` في Excel (صف العناوين موجود، لا تغيّره). الملف `dose-rates.example.csv` مثال وهمي للشكل فقط ولا يُقرأ.
2. أضف صفًا لكل (منتج + محصول + تربة + ري [+ مرحلة نمو]). كل الحقول إلزامية عدا مرحلة النمو.
3. احفظ بصيغة **CSV UTF-8** (Excel: حفظ باسم ← CSV UTF-8).
4. من مجلد المشروع شغّل: `python3 scripts/build_rates.py`
   - عند وجود خطأ يطبع رقم الصف والسبب ولا يغيّر الموقع.
   - عند النجاح يكتب `client/src/data/approvedRates.generated.ts` (لا تعدله يدويًا).
5. انشر الموقع من جديد.

| العمود | القيم المقبولة |
|---|---|
| نوع التربة | رملية، طينية، كلسية |
| نظام الري | تنقيط، رش، سطحي، بعلي، أخرى |
| المعدل | رقم موجب (الأرقام العربية والفاصلة مقبولة) |
| الوحدة | `kg/dunum` `L/dunum` `kg/ha` `L/ha` (أو كغ/دونم، لتر/دونم، كغ/هكتار، لتر/هكتار). الدونم = 1000 م² ويُحوَّل تلقائيًا |
| المعتمد من / المصدر | اسم المهندس المعتمد ومصدر المعدل (بطاقة المنتج مثلًا) |
| تاريخ المراجعة | بصيغة 2026-11-07 |

قواعد: لا يتكرر صف بالمفاتيح نفسها، وإذا حددت مرحلة نمو لمنتج فحدّدها لكل صفوفه. الحاسبة لا تحسب إلا ما يطابق صفًا هنا، وما عداه تحيله إلى المهندس.
