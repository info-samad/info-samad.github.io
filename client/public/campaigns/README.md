# الإعلانات الموسمية

تُعرض الإعلانات في قسم «الإعلانات» بعد واجهة البداية في الصفحة الرئيسية.

لإضافة إعلان جديد عند وصول مادة إعلانية أو بدء مرحلة جديدة من الموسم:

1. ضع الصورة الأصلية في هذا المجلد باسم وصفي جديد، ويفضّل عدم استبدال الإعلان الحالي إذا كان لا يزال مهمًا.
2. أضف بطاقة الإعلان في مكوّن `Campaigns` في `client/src/pages/Home.tsx`، مع عنوان ومرحلة الموسم ونص بديل يصف الصورة بدقة.
3. اربط الصورة بمسارها ابتداءً من `campaigns/` مع استخدام `import.meta.env.BASE_URL` حتى يعمل الموقع على GitHub Pages.
4. راجع النص والجرعات والتوصيات مع المعمل، ثم نفّذ `pnpm check` و`pnpm build:static` قبل نشر التحديث.

الموقع ثابت؛ لا يتغير محتواه تلقائيًا عند وصول ملف جديد. يحتاج كل إعلان جديد إلى إضافة ملفه وتحديث مصدر الصفحة ثم نشر نسخة جديدة.
